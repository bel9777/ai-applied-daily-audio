# ai-applied-daily-audio

AI Applied Daily: the AI Applied course as a two-host podcast (Alex and
Jordan), one episode per course day.

- Feed: https://bel9777.github.io/ai-applied-daily-audio/feed.xml
- Site (GitHub Pages from `docs/` on `main`): https://bel9777.github.io/ai-applied-daily-audio/
- Weekly collections feed: https://bel9777.github.io/ai-applied-daily-audio/weekly.xml
  (audio hosted in the `ai-applied-weekly-audio` repo)

Episodes are generated by `podcast.py` from the daily course emails (via the
`ai-applied-kindle` repo) using Gemini text + multi-speaker TTS.

    py podcast.py            # status only
    py podcast.py --run      # generate, publish, push
    py podcast.py --run --limit 3
