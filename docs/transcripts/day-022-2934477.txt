Jordan: It proves you tested the exact same input without duplicating sensitive text across your records. Anyone can re-hash your case files to confirm the test population never drifted. Jordan: Three common traps. First is hitting free-tier rate limits. If you see HTTP 429 errors in the ledger, you probably tested by hand too many times in one day. That usually means your API key environment variable was not visible to the background session, or you did not provide the full interpreter path.
Alex: And the third?
Jordan: Model deprecation. If you suddenly see HTTP 404 across every case, the provider retired or renamed the model. Because these models update frequently, keep the model name as a configurable setting rather than hardcoding it into the script.
