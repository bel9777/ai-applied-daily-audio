# AGENTS.md

All agent rules for this repo live in **CLAUDE.md** - read that first, then
`docs/current-state.md` for the live handoff. (`docs/` is also the GitHub
Pages webroot; `current-state.md` there is harmless but is the one doc kept
in that folder.)

The pipeline is `podcast.py` (daily), `weekly.py` (weekly collections),
`regen_episode.py` (force re-render). `py podcast.py` is status-only and safe.
